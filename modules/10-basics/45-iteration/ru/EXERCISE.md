
Напишите функцию `average()`, считающую среднее арифметическое для всех чисел в диапазоне. Функция должна возвращать Float:

```ruby
average(5, 8) # (5 + 6 + 7 + 8) / 4; 26 / 4; 6.5
average(2, 4) # (2 + 3 + 4) / 3; 9 / 3; 3.0
```

В Ruby при делении целых чисел на выходе всегда получается целое число. Если при этом была дробная часть, она отбрасывается. Чтобы получить число с дробью, нужно вызвать метод `.to_f()`

```ruby
3 / 2 # 1
3.to_f / 2 # 1.5
```
